# SaySell Releases

Repositório público destinado à distribuição dos instaladores do **SaySell para Windows** e dos arquivos de atualização, por meio de [GitHub Releases](https://github.com/MRsRIQUE/saysell-releases/releases).

## Downloads

Quando uma versão estiver disponível, baixe o instalador `.exe` nos **Assets** da release correspondente. Consulte as notas da versão antes de instalar.

Os arquivos `latest.yml` e `.blockmap`, quando gerados pelo empacotamento, acompanham o instalador para uso pelo atualizador. A existência deste repositório, por si só, não configura nem valida as atualizações automáticas do aplicativo.

## Verificação e assinatura

Publique somente builds verificados conforme a [checklist de publicação](RELEASE_CHECKLIST.md). A presença de um arquivo neste repositório não representa certificação de segurança.

Neste estágio, a distribuição não conta com assinatura de código Authenticode. Não há garantia de reconhecimento do editor pelo Windows, e o sistema pode exibir avisos. Não desative proteções de segurança para instalar.

Checksums ajudam a conferir a integridade dos arquivos, mas não comprovam a identidade do editor nem protegem contra um publicador comprometido.

## Código e direitos

O código-fonte proprietário do SaySell permanece em um repositório separado. Este repositório destina-se apenas à distribuição e à documentação pública das versões; sua visibilidade pública não concede uma licença sobre o aplicativo ou seu código-fonte.
